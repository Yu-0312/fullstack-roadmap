# 雙軌全端養成計畫

一份前端與後端並行的自學路線，做成可勾選的網頁追蹤器。

**線上版本：** https://yu-0312.github.io/fullstack-roadmap/

## 這份計畫在做什麼

5 條軌、33 個階段、237 個能力點，約 804 小時。

| 軌 | 階段 | 時數 | 內容 |
| --- | --- | --- | --- |
| 共同地基 | 4 | 40h | 命令列、Git、一個網址背後發生的事、除錯心法 |
| 前端軌 | 9 | 262h | HTML 語意 → CSS → JavaScript 核心 → DOM → Node/npm 工具鏈 → TypeScript → React → Next.js → 工程化與測試 |
| 後端軌 | 9 | 246h | Python → 演算法 → HTTP/API → 資料庫 → 認證與安全 → Linux → Docker/CI → 非同步與佇列 → Node/TS 對照 |
| 畢業專案 | 5 | 100h | 從規格到上線的完整全端產品 |
| 面試軌 | 6 | 156h | 刷題、專案敘事、系統設計、技術深問、中英表達、投遞衝刺 |

## 三個設計原則

**以過關推進，不以週數推進。** 這裡沒有日期。每張卡上的「前置」說明它需要先學會什麼，「過關條件」說明什麼時候可以往下走。

**任何一張卡片裡出現的工具或概念，一定在它的前置階段裡教過。** HTML/CSS 階段不需要安裝任何東西；JavaScript 只寫純邏輯，畫面操作留到下一階段；Node、npm、Vite 在需要安裝第一個套件之前才登場；後端的 API 先用同步寫法，容器排在訊息佇列之前。

**「熟練」有三個層次**，每個項目都要走到第三層才算勾完：查著文件寫得出來 → 不查文件寫得出來 → 能解釋為什麼這樣做、還有哪些選項。

## 技術說明

單一 HTML 檔，沒有建置步驟、沒有相依套件。進度用 localStorage 存在瀏覽器本機，換裝置不會同步。

```bash
# 本機預覽
open index.html
```
